# Driving Lab

The software uniting all devices in the Driving lab in a single service. Can

- stream data
  - also to a log file
- stream events 
- execute requests

Supported devices:

- Leap Motion
- Tobii EyeX
- VI myGaze

## Projects

- Core: Definitions of gRPC services
- Server: gRPC server. 
- ClientExample: An example of gRPC client (C# .NET 10)
